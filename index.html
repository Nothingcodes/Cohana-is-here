    About Memory
    Memory lets Cohana retain useful details from previous conversations, such as preferences, facts, and instructions. When Memory is enabled, saved memories may be included as context in future conversations and new memories may be stored. Turning Memory off stops Cohana from using or saving memories; it does not delete existing memories.
